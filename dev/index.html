API Reference

🔥 Metabolic rate

Basal metabolic rate of mammals and birds, standard metabolic rate of squamate reptiles with body temperature, and plant respiration.

🦎 Morphology

Surface, skin, plumage and silhouette areas, skeleton and brain mass, and body-part proportions for heat and mass budgets.

🫀 Physiological time

Heart rate, lung and tidal volume, stride frequency, cost of transport, lifespan and generation time.

🍃 Leaves

Leaf area from length and width with the Montgomery model for different plant families, and leaf dry mass from area.

🦴 Structural constraints

Limb diameter and length under elastic and geometric similarity, as shape parameters for body geometry.

📏 Units and references

Every equation takes and returns Unitful.jl quantities, and carries the literature reference it comes from.

How to install BiologicalScaling.jl? ​

BiologicalScaling.jl can be installed from the Julia REPL:

julia
julia> using Pkg
julia> Pkg.add("BiologicalScaling")
# or
julia> ] # ']' should be pressed
pkg> add BiologicalScaling

If you want to use the latest unreleased version, you can run the following command:

julia
julia> using Pkg
julia> Pkg.add(url = "https://github.com/BiophysicalEcology/BiologicalScaling.jl")

Manual ​

BiologicalScaling.jl is a standalone package of empirical scaling equations for estimating biological traits from body size. It is also part of the BiophysicalEcology ecosystem for mechanistic niche modelling, where it provides the sizes, shapes and rates of organisms: metabolic rates for ThermalPhysiology.jl to correct for temperature, and body areas and proportions for the heat budgets of HeatExchange.jl and the body shapes of BiophysicalGeometry.jl. See the Introduction for the design of the package.
